# Show HN: Construí uma Ferramenta para Simplificar Saída de CLI do Claude Code - Local Log Viewer

*Ferramenta para visualizar logs do Claude Code de forma mais amigável.*

**[Fonte: GitHub], [18/02/2026]** – Lançando o Local Log Viewer, uma ferramenta que processa e formata logs de CLI do Claude Code.

### O Problema

Saída de CLI do Claude Code pode ser difícil de ler e navegar. 
Logs não possuem formatação visual ou destaque de sintaxe. 
Difícil rastrear conversas longas ou encontrar informações específicas.

### A Solução

Interface web local para visualização de logs. 
Formatação automática com destaque de código e markdown. 
Filtros e busca para navegação eficiente.

### Recursos

Importação de arquivos de log diretamente do diretório do Claude Code. 
Exportação para formatos markdown e HTML. 
100% local - nenhum dado enviado para servidores externos.

### Como Usar

Disponível no GitHub com instruções de instalação. 
Funciona com qualquer versão do Claude Code. 
Código aberto sob licença MIT.
